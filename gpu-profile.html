GPU inference: profile of every simulation stage

Measured October 15, 2026 · RTX 5090 · 4,000 particles · 5 ms simulation timestep.

Complete step: 15.73 ms mean; 19.79 ms p95. All non-neural physics stages now execute in Warp on GPU. PyTorch runs the neural network using shared CUDA buffers. No MPM runs during inference.

What changed

GPU neighbor search replaces SciPy’s CPU tree. Warp computes geometry features, particle integration, static-tray correction, velocity gradients, contact geometry, contact impulses, and body forces. Material features are uploaded once. Particle/body states stay on GPU between steps. The default demo retains the small recorded bed and matte brown/grey appearance.

cd ~/isaac/particle_nerd
./play.sh
# Optional faster rasterized viewer with the same colors:
./play.sh --viewer gl

The graph uses every directed particle pair within 0.035 m. A fixed-capacity buffer contains masked padding. Overflow raises rather than silently discarding neighbors. Every particle is updated. The contact solver uses parallel relaxed updates with the same unilateral contact and Coulomb friction equations; its stopping criterion is an unrelaxed impulse change below 1e-9 N s. A safeguarded root solve replaces fixed 45-iteration friction bisection.

CPU/GPU transfer audit

A CUDA trace over five warmed steps found zero device-to-host transfers in the physics step. Warp’s hash-grid builder uploads one 88-byte configuration descriptor per step. No particle/body state or solver stopping decision is sent to CPU. UI plots and CSV logs read data explicitly outside the physics step.

MJWarp’s rigid substep is CUDA-graph captured to keep its convergence decisions on GPU. The complete Warp + PyTorch step is not yet graph captured.

Validation

  • 20 focused tests pass, covering reduced-mass impulses, Coulomb friction, contact moments, external forces, backend parity, buffer overflow, and rejection of host state transfers inside a step.
  • Box, sphere, and cylinder complete the 300-step profiling rollouts without contact-solver convergence failures.
  • After 300 box steps, GPU/reference particle-coordinate RMSE is 4.32 µm; box-center distance is 3.77 µm; final material-force difference is 0.000600 N.

These are implementation-parity checks against the previous estimator, not accuracy improvements against MPM. The learned model, material assumptions, and training distribution are unchanged.
