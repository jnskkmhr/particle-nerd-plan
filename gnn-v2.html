Answers to the architecture questions

Is the GNN built from MLPs?

Yes. The released implementation has MLP node and edge encoders, shared linear/ReLU message propagators with a node residual connection, and an MLP that outputs three displacement values.

Is the proposer a CNN around the tool?

Yes. It rasterizes terrain and tool position histories into tool-centered heightmaps. A multiscale CNN combines these maps with a motion embedding and predicts one activation depth per horizontal cell.

Ground versus dynamic box?

Both are rigid geometry. For this implementation, the fixed ground is an analytical plane feature; the moving box is sampled into surface graph nodes carrying its current surface motion. These are physical roles, not object categories.

Sources: L-GBND paper, Sections III–IV; released implementation, pinned revision. The public repository is an architecture extraction, without trained weights or a complete benchmark.

02 / What spatial structure does selection enforce?

Each horizontal cell has one depth boundary. This prevents independent activation decisions at different depths in that column. Convolutions share information between nearby cells. The network does not impose strict horizontal connectedness or a universal rule that motion decreases with distance from the box.

Settling, avalanching, and transmitted contact can move material away from the box. Stationary-particle drift is a prediction error; distance from the box alone does not establish that a particle should remain stationary.
