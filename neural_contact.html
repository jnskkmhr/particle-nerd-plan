01 / Why Both Previous Force Models Failed

1. Analytical Effective-Mass Solver

Modelled each candidate contact particle \(i\) as an isolated point mass \(\kappa m_i\) in free space (\(v_{\text{aux},i} = \hat{v}_i^{n+1} - j_i / (\kappa m_i)\)). Because Transolver already predicts post-contact velocity \(\hat{v}_i^{n+1}\), static support depends artificially on \(\kappa\): \(\kappa = 10\) loses half the box weight (37.6 N vs. 73.6 N), while \(\kappa = 180\) amplifies autoregressive particle velocity noise into 176–182 N force errors on the shovel.

2. Global Token Pooling Impulse Head

Averaging particle tokens into a single collider vector before decoding force (\(\sum_i w_i h_i\)) erases where each particle touches the collider surface. Once spatial coordinates are averaged before force prediction, the moment arm \(\mathbf{r}_{ib} \times \mathbf{f}_{ib}\) is lost—making accurate pitching/rolling torque and center-of-pressure mathematically unrecoverable.

3. Full-Bed 16,384-Particle Attention

In a 16,384-particle sand bed, 85–95% of particles far from the moving tool are stationary during any 20 ms step. Running all 16,384 particles through Transolver caused 29–60% of stationary particles to drift >1 cm over 5 s and created a 512 MiB slice tensor at 32 worlds (~50 ms neural forward).

02 / Generic Physics-Structured Neural Contact Head & Quadrature Compaction

All colliders—including the fixed rigid ground plane beneath the sand (\(\mathbf{V}_b = \mathbf{0}, m_b^{-1} = 0, \mathbf{I}_b^{-1} = \mathbf{0}\)) and dynamic rigid bodies (box, concave shovel SDF, or robot links)—share the same physical representation without semantic class labels: 

For each candidate contact particle i near collider b (top K_c = 512 by collider influence):
  1. Exact surface contact point & moment arm about collider b's center of mass c_b:
       s_ib = x_i^n - d_ib * n_ib,    r_ib = s_ib - c_b
  2. Point inverse-inertia (mobility) of collider b along outward normal n_ib at s_ib:
       w_body,ib = (1 / m_b) + (r_ib x n_ib)^T I_world,b^-1 (r_ib x n_ib)
       (Identically zero for infinite-mass rigid ground; exact lever-arm compliance for finite-mass bodies)
  3. Quadratic B-spline contact gate from current gap g_ib and predicted next gap g_hat_ib:
       g_eff,ib = min(g_ib, g_ib - dt * n_ib · (V_surf,free,ib - v_hat_i^{n+1}))
       phi_ib   = clamp(1 - max(g_eff,ib, 0) / R_c, 0, 1)^2 * 1(g_ib < support)
  4. Decomposed per-particle unilateral normal force (along -n_ib, material on collider):
       f_n,ib = f_scale,ib * [ softplus(z_stat) + softplus(z_pen) * ReLU(-g_eff,ib / R_c)
                             + softplus(z_dem) * ReLU(u_n,demand) + softplus(z_post) * ReLU(u_n,post) ] >= 0
  5. Tangential friction force strictly inside the isotropic Coulomb cone ||f_t,ib|| <= mu_b * f_n,ib:
       f_t,ib = mu_b * f_n,ib * tanh(||w_perp,ib||) * (w_perp,ib / ||w_perp,ib||)
  6. Exact per-particle moment-arm summation + contact-gated body-frame continuum refinement:
       F_surf,b   = sum_i ( -n_ib * f_n,ib + f_t,ib )
       tau_surf,b = sum_i r_ib x ( -n_ib * f_n,ib + f_t,ib )
       W_b^{(s)}  = W_0,b - D_world,b * (V_b^{(s)} - V_b^n)   (200 Hz passive substep damping)

Quadrature-Weighted Active-Particle Compaction

Why did naive top-\(K\) particle selection degrade pre-trained Transolver accuracy? Because Transolver's slice normalization \(\tilde{w}_{i,s} = w_{i,s} / \sum_{j=1}^N w_{j,s}\) was trained over all \(N = 16,384\) particles; dropping \(N - K\) stationary background particles alters the slice denominator. Our encode_compact layer selects \(K\) active particles (by proximity to dynamic colliders and kinetic speed) plus \(M = 64\) strided background anchor particles carrying quadrature multiplicity weight \((N - K)/M_{\text{valid}}\). This preserves the exact 16,384-particle slice distribution while running the network on only \(K + M\) particles and setting \(\Delta \mathbf{x} = \mathbf{0}\) outside the active set.
